# Netflix Clone

A Netflix-inspired frontend project built for learning and practicing web development using HTML and CSS.

## 🚧 Status

Work in Progress

## 🛠️ Technologies

- HTML5
- CSS3
- Responsive Design

## ✨ Features

- Netflix-inspired navigation bar
- Netflix logo and branding-style layout
- Language selector
- Sign-in button
- Responsive hero section
- Full-screen background image
- Dark overlay for improved text readability
- Email signup section
- Trending movies section
- Horizontal movie carousel layout
- Responsive movie cards
- Movie numbering design
- "More reasons to join" feature section
- Frequently Asked Questions (FAQ) section
- Responsive footer
- Hover effects
- Smooth horizontal scrolling
- Responsive layouts for mobile, tablet, and desktop screens

## 📱 Responsive Design

The website is designed to adapt to different screen sizes:

- 📱 Mobile devices
- 📱 Tablets
- 💻 Desktop screens

Responsive layouts are implemented using CSS media queries.

## 🎯 Purpose

This project was created as a learning exercise to practice:

- HTML5 structure
- Semantic HTML
- CSS styling
- Flexbox
- CSS Grid
- Responsive design
- Media queries
- Background images
- Positioning
- Hover effects
- Smooth scrolling
- Building a website inspired by an existing design
